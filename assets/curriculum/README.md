# 교육과정 및 평가 자료

`data/curriculum.json`은 원문 성취기준·해설·대단원 고려 사항, 원문 표의 셀/병합/열 너비, 현재 등록된 단원과의 연결을 담습니다. 단원 코드만으로 연결하지 않고 과목·대단원 번호·중단원 번호도 구분합니다. 과목 공통 교수·학습 지침은 단원 모달에 포함하지 않습니다.

2022 내용 체계표는 핵심 아이디어, 지식·이해, 과정·기능, 가치·태도를 포함합니다. 2015는 해당 버전의 원래 내용 체계 및 대단원 교수·학습/평가 유의 사항을 사용합니다. 원문에 개별 해설이 없는 성취기준은 해설을 새로 작성하지 않습니다. 중학교 지리처럼 여러 내용 영역을 함께 다루는 경우 관련 공통 표 전체를 표시합니다.

- `social-2022.pdf`: 사용자가 제공한 교육부 고시 제2022-33호 별책 7. [교육부 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&statusYN=W). PDF 페이지 = 인쇄 페이지 + 6.
- `social-2015.pdf`: 교육부 고시 제2015-74호 별책 7. [교육부 고시 및 원본 ZIP](https://www.moe.go.kr/boardCnts/view.do?boardID=141&boardSeq=60747&lev=0&m=040401&opType=N&page=5&s=moe&searchType=S). PDF 페이지 = 인쇄 페이지 + 4.
- `evaluation-middle-social.pdf`: [NCIC 중학교 사회 2022 성취수준](https://ncic.re.kr/bbs/standard/view/770.do), 2024-09-05. 사회1·사회2 공통 문서 전체.
- `evaluation-integrated-social-{1,2}.pdf`: [NCIC 고등학교 사회과 공통과목 2022 성취수준](https://ncic.re.kr/bbs/standard/view/783.do), 2024-09-05. 통합사회1 PDF 29–114쪽, 통합사회2 115–225쪽을 발췌.
- 고등학교 선택과목 `evaluation-*.pdf`: [NCIC 사회과 선택과목 성취수준 현장 보급본](https://ncic.re.kr/bbs/standard/view/1404.do), 2025-07-22. 사회와 문화 97–164쪽, 정치 327–388쪽, 법과 사회 389–466쪽, 경제 467–528쪽, 국제 관계의 이해 529–598쪽, 사회문제 탐구 669–762쪽, 금융과 경제생활 763–846쪽을 발췌. 각 과목의 성취기준별·영역별 수준과 예시 평가도구를 포함.
- `evaluation-middle-social-2015.pdf`: [NCIC 2015 사회과 평가기준 및 연구 보고서](https://ncic.re.kr/bbs/standard/view/736.do), 2017-02-15. 평가기준 개발 연구 원문 전체. 별도 평가기준 HWP도 공식 배포 페이지에서 제공.

확인일: 2026-10-09. 문서 SHA-256, 공식 배포/다운로드 URL, 발췌 PDF 페이지 범위는 JSON에 기록합니다. 발췌본은 원문 페이지를 수정하지 않았습니다. 단원표 또는 고시가 바뀌면 연결을 갱신하고 `node scripts/test-curriculum.mjs`를 실행합니다. 중단원–성취기준 연결은 사이트의 수업 편의를 위한 편집이며 공식 교과서 단원 편성 지침이 아닙니다.

`data/achievement-levels.json`에는 2022 개정 평가 문서에서 추출한 성취기준별 A–E 수준 196개와 영역별 A–E × 지식·이해/과정·기능/가치·태도 표 62개를 담습니다. 중단원은 기존 성취기준 코드로 연결하고, 대단원은 성취기준별 표 전체와 영역별 표를 함께 표시합니다. 2015 개정은 사용자 요청에 따라 이 탭에서 제외했습니다. 자료는 모달을 열 때 별도로 불러오며 DB에 저장하지 않습니다.

재생성: `python3 scripts/extract-achievement-levels.py` (`pdfplumber` 필요). 체크인된 과목별 발췌 PDF를 읽습니다. 셀 경계에 걸친 글자는 중심점으로 배정하고, 페이지를 넘긴 셀을 합칩니다. 추출된 본문과 원문 본문의 문자 수, 영역명, 단원별 성취기준 코드와 수준 완결성을 검증합니다. 통합사회1의 05 영역은 평가 문서에서 ‘생활공간의 변화’로 표기하므로 교육과정의 ‘생활공간과 사회’와 코드로 연결하며 원래 평가 문서 영역명도 표시합니다. 페이지 링크는 발췌본의 PDF 페이지를, 출처 표기는 원본 합본의 인쇄 페이지를 사용합니다.

성취수준 표는 원문의 성취기준/영역 왼쪽 병합 셀과 상단 성취수준 병합 머리글을 유지합니다. 성취기준 셀의 문장은 교육과정에서 재조합하지 않고 평가 문서에서 직접 추출합니다. ‘한글 표 복사’는 HTML 표와 탭으로 구분한 텍스트를 클립보드에 함께 기록합니다. HTML에는 병합 셀과 테두리, 문서에 맞는 열 너비를 포함합니다. Clipboard API를 사용할 수 없는 환경은 `copy` 이벤트로 같은 형식을 기록하며, 표 복사에 실패하면 성공 메시지를 표시하지 않습니다. HTML의 성취기준 5행 병합, 영역 15행 병합, 상단 2열/3열 병합을 검사하며, 텍스트 형식에서는 병합 셀의 내용을 각 행에 반복해 열 수를 유지합니다.

복사 회귀 검사: 로컬 서버를 실행한 상태에서 `node scripts/test-curriculum-copy.mjs` (기존 Playwright 필요, 별도 런타임이면 `PLAYWRIGHT_MODULE`로 모듈 경로 지정). 표 병합, 텍스트 열 수, 복사 실패 복구 및 Clipboard API가 제한된 환경의 대체 동작을 검사합니다.
