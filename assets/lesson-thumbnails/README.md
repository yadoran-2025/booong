# 수업 대표 이미지 관리

## 관리자 화면에서 수정

운영자 공간의 **썸네일 관리**에서 수업을 검색하고 **이미지 수정**을 누릅니다. 파일 선택·드래그·붙여넣기 버튼 또는 Ctrl+V(맥은 ⌘V)로 이미지를 넣은 뒤, 확대와 위치를 조절하고 카드 미리보기를 확인해 저장합니다. 새 이미지는 브라우저에서 800×500 WebP(품질 85%)로 변환해 저장하며 최대 2MB입니다. 기존 PNG도 조회·복원할 수 있고, 다시 저장하면 WebP로 바뀝니다. **이전 이미지로 복원**은 직전 이미지 한 개로 돌아갑니다. 다시 누르면 교체한 이미지로 돌아갈 수 있습니다.

관리 화면에서 저장한 이미지가 수업 시트의 `thumbnail_url`, 아래의 정적 화면 캡처, 기본 이미지보다 우선합니다. 수업 ID는 바꾸지 않습니다.

배포 환경은 Firebase 프로젝트 `yadoran-2025`의 전용 콘텐츠 DB `content/thumbnails`와 기존 Storage 버킷의 `booong/managed-content/thumbnails/images/`를 사용합니다. 서버 전용 `FIREBASE_BOOONG_CONTENT_SERVER`로 연결하며 이미지 원본은 비공개입니다. 카드 이미지만 공개 API를 통해 전달합니다. 변경 사항은 수업 목록 새로고침으로 반영됩니다. 관리자 인증과 같은 출처 검사를 통과한 요청만 이미지를 수정할 수 있습니다.

공개 목록은 CDN과 서버에서 각각 30초 동안 캐시하므로 변경이 모든 방문자에게 보이기까지 약 1분 걸릴 수 있습니다. 동시 요청은 저장소 조회 한 번으로 합치고, 이미지는 서버 메모리에서 최대 32MB까지 재사용합니다. 현재·직전 썸네일로 등록되지 않은 이미지 ID와 불필요한 쿼리는 저장소를 읽지 않고 거절합니다. 관리자 조회와 저장·복원에는 캐시를 사용하지 않습니다.

Vercel 방화벽의 `BOOONG thumbnail request limit` 규칙은 `/api/lesson-thumbnails`와 내부 별칭 `/api/admin?thumbnail=1`을 대상으로 IP당 지역별 분당 600회를 허용합니다. 일반 `/api/admin` 요청은 이 규칙에 포함되지 않습니다. 초과하면 429 응답을 반환합니다. 앱에도 인스턴스별 동일한 제한이 있어 로컬 실행과 방화벽을 통과한 반복 요청을 제한합니다. 여러 서버 인스턴스에 걸친 제한은 방화벽이 담당하지만, 서로 다른 IP·지역에서 오는 요청은 각각 집계합니다. 별도 DB·유료 요금제는 추가하지 않습니다.

`npm run serve`로 실행한 로컬 환경에서는 `.data/lesson-thumbnails/`에 별도로 저장합니다. 로컬에서 수정한 이미지는 배포 환경으로 전송되지 않습니다. 원본 이미지 파일은 변경하지 않습니다.

## 파일과 시트에서 직접 관리

수업 정보는 기존 수업 시트(`gid=1091433397`), 이미지 파일은 이 폴더에서 관리합니다. 사이트는 시트의 공개 CSV를 읽으므로 셀에 이미지를 삽입하는 대신 이미지 파일의 주소를 적습니다.

수업 시트에 다음 두 열을 추가합니다. 열 순서는 상관없습니다.

| 열 | 입력 예시 | 용도 |
| --- | --- | --- |
| `thumbnail_url` | `/assets/lesson-thumbnails/popgrid-v1.webp` | 사이트에서 바로 읽을 수 있는 이미지 주소 |
| `thumbnail_alt` | `세계지도에서 인구가 많은 칸을 고르는 조별 활동` | 이미지를 설명하는 짧은 문장. 생략하면 수업 제목을 사용합니다. |

## 새 수업 등록 순서

1. 기존 방식대로 수업 행을 등록합니다. 이미지가 없어도 수업은 표시됩니다.
2. 수업 제목·설명·학생이 하는 활동을 바탕으로 AI 이미지를 만듭니다. 권장 크기는 **800 × 500px(16:10)**, 형식은 WebP·JPG·PNG입니다. 이미지 안의 작은 글씨는 피하고 핵심 활동을 보여줍니다.
3. 확정한 파일을 이 폴더에 `popgrid-v1.webp`처럼 짧은 이름으로 저장하고 사이트 배포에 포함합니다. 가능하면 300KB 이내로 압축합니다.
4. 해당 수업 행의 `thumbnail_url`에 `/assets/lesson-thumbnails/popgrid-v1.webp`를 넣고 `thumbnail_alt`를 적습니다.
5. 홈페이지를 새로고침해 PC·모바일에서 확인합니다. 공개 CSV 반영이 지연되면 잠시 뒤 다시 확인합니다.

이미지 수정본은 `popgrid-v2.webp`처럼 새 이름으로 저장하고 시트의 주소를 바꿉니다. 파일을 같은 이름으로 덮어썼을 때 이전 이미지가 캐시에 남는 문제를 피할 수 있습니다. 이미지 교체 때문에 기존 `resource_id`·`group_id`를 바꾸지 않습니다. 해당 ID에 연결된 저장·댓글·통계가 있기 때문입니다.

외부에서 호스팅한다면 로그인 없이 이미지 자체가 열리는 HTTPS 주소를 입력해도 됩니다. 문서나 공유 페이지 주소는 사용할 수 없습니다. 주소가 비어 있거나 이미지 로딩에 실패하면 같은 이미지 영역에 AI로 생성한 사회 수업 기본 이미지 4종를 표시합니다. 수업 내용·만든이·통계는 유지합니다.

관리자 화면을 사용하지 않는 경우에는 이 폴더와 시트 두 열로도 이미지를 연결할 수 있습니다.

수업 설명(`desc`)은 카드에서 기본 세 줄까지 표시합니다. 세 줄을 넘으면 설명 끝 바로 옆의 `더 보기`로 전체 설명을 펼치고, `접기`로 돌아올 수 있습니다. PC·모바일에서 실제 줄 수를 기준으로 버튼을 표시합니다. 만든이와 조회수·저장수·댓글은 이미지 유무와 관계없이 카드 전체 폭의 하단에 표시하며, 집계 기록이 없는 항목도 0으로 표시합니다.

기본 이미지는 `social-studies-default-v1.jpg`(지리·토론), `civics-default-v1.jpg`(시민사회), `economics-default-v1.jpg`(시장·거래), `history-default-v1.jpg`(역사 탐구)입니다. 페이지를 열 때 순서를 무작위로 섞고 수업마다 순환 배정합니다. 같은 페이지 안에서는 과목·단원을 바꾸어도 같은 수업의 이미지를 유지합니다. 새로고침하면 배정 순서가 다시 섞입니다. 관리 화면에서 저장한 이미지가 없다면 `thumbnail_url`에 직접 등록한 이미지를 우선 표시합니다.
