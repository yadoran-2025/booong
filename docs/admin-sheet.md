# 관리자 Google 계정

기존 멤버 프로필 시트(`gid=1259304881`)에 `admin` 열을 추가하고 관리자의 Google 이메일을 입력합니다. 한 셀에 계정 하나를 적습니다. 공백과 대소문자 차이는 무시하며 빈 셀은 권한을 부여하지 않습니다. 권한을 회수하려면 해당 이메일을 지웁니다.

| id | name | admin |
| --- | --- | --- |
| 기존 멤버 코드 | 기존 멤버 이름 | 관리자의 Google 이메일 |

추가 시트나 환경 변수는 필요하지 않습니다. 기존 멤버 프로필 CSV 게시 주소를 그대로 사용합니다. 서버는 관리자 명단을 최대 30초간 재사용하고 동시 조회를 합칩니다. 이메일 삭제에 따른 권한 회수는 최대 30초 뒤 반영됩니다. 로컬 프로필, 제작자 코드, 브라우저 저장값으로 권한을 부여하지 않습니다. 캐시 만료 후 시트가 미설정이거나 읽기에 실패하면 이전 명단으로 접근을 허용하지 않습니다.

Google 로그인은 기존 BOOONG Firebase 웹 앱(`1:266288546185:web:727060b22ce9643d0c2158`, 프로젝트 `yadoran-2025`)을 사용합니다. 서버는 Firebase ID 토큰의 서명·발급자·대상 프로젝트·만료·Google 로그인 여부·이메일 인증을 검증한 뒤 시트의 `admin` 값과 대조합니다. 도름스 댓글 로그인은 기존 흐름을 유지합니다.

Firebase Authentication의 Google 제공자가 활성화되어 있어야 하고 이 앱의 서비스 도메인만 Authorized domains에 등록되어 있어야 합니다. 2026-10-01 재확인 기준 Google 제공자와 `booong.vercel.app` 승인 도메인이 설정되어 있습니다. 다른 앱의 인증 설정이나 도메인은 변경하지 않습니다.

관리자 메뉴, 방문 통계, 교과서 분석은 진입 시 권한을 확인합니다. 같은 화면에서의 관리자 확인 결과는 계정별로 최대 30초간 재사용하며 재확인 중 기존 화면을 유지합니다. 교과서 진입은 보호된 카탈로그 요청으로 권한 확인을 함께 처리하고, 카탈로그·PDF 요청마다 서버에서 Google 토큰을 검증합니다. 이 변경은 화면 접근을 제한하며 기존 Firebase 통계 원본의 공개 읽기 규칙은 유지됩니다.
