# 수업 관리

운영자 공간 → **수업 관리**에서 기존 구글 시트를 처음 한 번 가져옵니다. 수업·단원 시트를 함께 가져오며 비공개 수업, 기존 수업 ID와 추가 열도 보존합니다. 기존 시트를 변경하거나 삭제하지 않습니다.

**수업 등록**은 모달에서 작성합니다. 닫기·취소·Esc로 닫을 수 있으며, 작성 중이면 버릴지 확인합니다. 기존 편집 화면의 입력 내용은 유지합니다. 등록 후에는 새 수업이 비공개로 추가되며, 기존 수업에 저장 전 수정 내용이 없으면 새 수업을 선택해 썸네일을 이어서 추가할 수 있습니다.

가져온 뒤에는 관리자 화면이 수업 목록의 원본입니다. 시트의 수정 사항을 자동으로 덮어씌우거나 재가져오지 않습니다. 제목·소개·제작자·자료 링크·과목과 단원을 수정할 수 있습니다. 새 수업은 비공개로 시작합니다. 삭제 대신 비공개로 보관합니다. 수업 ID는 수정할 수 없으며, 제목이나 단원이 바뀌어도 저장·댓글·조회수·썸네일 연결을 유지합니다.

수업 소개·교사용 자료·도름스 링크는 각각 한 줄 전체에 입력합니다. 저장이 끝나면 화면 하단에 완료 알림이 표시됩니다. 실패 시에는 오류 알림을 표시하고 입력을 유지합니다.

왼쪽 수업 목록의 **공개·신규 체크박스**는 체크 즉시 각각 저장합니다. 작성 중인 본문은 유지됩니다. 과목·단원이 저장되지 않은 수업은 먼저 편집 화면에서 단원을 저장한 뒤 공개합니다. 표시 설정은 해당 필드만 수정하며, 충돌·실패 시 체크를 원래대로 되돌리고 오류를 표시합니다. 편집 화면의 자료 유형 선택은 없앴습니다.

과목 버튼을 누르면 대단원별로 단원을 펼쳐 보여주는 모달이 열립니다. 단원을 복수 선택하고 **선택 적용**을 누르면 편집 화면의 단원 칩에 반영됩니다. 취소·닫기·Esc는 모달에서 바꾼 선택을 버립니다. 다른 과목의 선택은 유지되며, 선택한 단원이 있는 과목 버튼이 강조됩니다. 최종 변경은 수업의 **저장**으로 반영합니다. 수업 등록 모달에서도 같은 단원 선택을 사용합니다.

개별 수업의 **썸네일 → 이미지 수정**에서 파일 선택·드래그·붙여넣기와 확대·위치 조절을 할 수 있습니다. **썸네일 저장**은 이미지를 저장하며, 작성 중인 수업 정보는 유지됩니다. **이전 이미지로 복원**도 수업 화면에서 바로 할 수 있습니다. 비공개 수업의 이미지도 준비할 수 있으며, 새 수업은 먼저 저장한 뒤 이미지를 추가합니다.

**제작자 · 맡은 일**에서 기존 회원 코드 칩을 복수 선택하고 사람마다 한 일을 입력합니다. 회원 이름도 함께 표시합니다. 기존 제작자는 미리 선택되며 역할은 추정해서 채우지 않습니다. `contributors`에 코드·역할을 저장하고 기존 `maker` 문자열도 코드 목록으로 유지해 회원별 제작 자료 연결을 보존합니다. 수업 소개에는 코드와 입력한 역할이 함께 표시됩니다. 등록되지 않은 기존 코드도 보존합니다.

배포 환경에서는 기존 private Vercel Blob에 `booong-lessons/catalog.json`을 저장합니다. 별도 DB나 Firebase 리소스를 추가하지 않습니다. 조건부 쓰기(ETag)와 목록 수정 버전으로 동시 덮어쓰기를 방지합니다. 충돌하면 입력 내용을 유지하므로 필요한 내용을 복사한 뒤 새로고침합니다. 전체 목록 하나를 갱신하는 구조이므로 동시 편집이 잦아지면 수업별 저장소로 전환합니다. 최대 5,000개 수업·8MB 목록을 허용합니다.

공개 API `/api/lesson-catalog`는 공개 수업만 반환하며 CDN·서버에 각각 30초 캐시합니다. 수정 반영은 약 1분 걸릴 수 있습니다. 관리자 API는 Google 운영자 인증을 확인하며 캐시하지 않습니다. 저장은 같은 출처의 JSON 요청만 받습니다. 공개 API는 불필요한 쿼리를 거절하고 동시 읽기를 합치며, 장애 시 10초 동안 재요청을 줄입니다. 앱 요청 제한은 인스턴스별 IP당 분당 600회입니다. 운영 배포 시 기존 썸네일 WAF 규칙에 `/api/lesson-catalog`와 `/api/admin?catalog=1`을 함께 포함해야 합니다.

최초 가져오기 전에는 기존 시트를 계속 사용합니다. 수업 관리 전환 뒤에는 홈페이지가 공개 API를 우선 사용합니다. 구글 시트는 초기 수업·단원 가져오기와 기존 운영자 명단 확인에 사용됩니다.

저장소 연결이 실패하면 이미 확인한 관리자 목록의 공개 캐시만 재사용합니다. 캐시가 없으면 재시도 안내를 표시하며, 예전 시트의 공개 상태로 돌아가 숨긴 수업을 다시 표시하지 않습니다.

로컬 서버는 `.data/lesson-catalog/catalog.json`에 별도로 저장하며, 이 데이터는 Git이나 배포에 포함하지 않습니다. 운영 사이트에서도 최초 가져오기를 실행해야 합니다.

검증: `node scripts/test-lesson-catalog.mjs`, `npm test`, `npm run check`, `npm run smoke`.
