# 쌀바구니 통합

웹앱 편집은 모달 위쪽의 웹앱 버튼으로 한 개씩 선택하고 제목·저장 버튼은 항상 표시합니다. 다른 웹앱의 초안도 저장 때 함께 검증하며 오류가 있으면 해당 웹앱으로 이동합니다. 웹앱·유형·QR 모달은 바깥 배경을 클릭하면 취소처럼 닫히고 미저장 초안은 적용하지 않습니다. 저장 중에는 배경·닫기·Esc로 닫을 수 없습니다.

유형은 카드 그룹 제목에 표시하며 위쪽의 중복 목록은 표시하지 않습니다. 운영자는 웹앱 추가·설정 옆의 **유형 수정**에서 문구를 수정·추가·삭제하고 **웹앱 설정 → 유형**에서 각 웹앱의 유형을 선택합니다. 유형은 고유 ID와 문구로 저장해 이름 변경이나 다른 유형 삭제로 번호가 바뀌어도 연결을 유지합니다. 지정된 유형 자체를 삭제하면 해당 웹앱만 미지정으로 바뀌며 수업·링크·썸네일은 유지합니다. 기존 문자열 목록도 읽을 수 있으며 같은 수정 버전으로 충돌을 검사합니다.

새 웹앱은 **BOOONG 수업 고르기**에서 검색·선택합니다. 이름·썸네일·기본 교사 링크는 BOOONG 카탈로그와 대표 이미지에서 읽으며, 쌀바구니에는 수업 ID와 수정한 교사 링크·선택 학생 링크만 저장합니다. 기본 링크를 그대로 쓰거나 비우면 BOOONG 기본 링크를 사용합니다. 기존 직접 등록 웹앱은 원래 데이터와 캡처를 유지하며 **BOOONG 수업 연결**로 전환할 수 있습니다. 목록을 불러오지 못하면 새 수업 선택을 막고 기존 링크·등록 자료는 유지합니다.

웹앱은 유형 번호 순서로 묶고, 각 그룹 안에서 화면 폭에 맞춰 최대 3열 카드 목록으로 표시합니다. 빈 그룹은 표시하지 않으며 미지정 웹앱은 마지막에 모읍니다. 그룹 안에서는 등록 순서를 유지하고 QR 요청은 저장된 웹앱의 원래 번호를 사용합니다. 학생 URL이 있는 카드의 **학생 QR** 버튼을 누를 때 해당 QR을 불러와 대화상자로 확대하며, 학생 화면 열기·링크 복사도 같은 창에서 제공합니다.

기존 직접 등록 웹앱은 **캡처 이미지 붙여넣기** 버튼이나 해당 웹앱 입력란에서 이미지 붙여넣기를 지원합니다. 저장하면 캡처가 자동 미리보기보다 우선하며, 취소하면 기존 이미지를 유지합니다. 캡처는 원본 비율을 유지한 800×500 JPEG(최대 128KB)로 기존 비공개 페이지 저장소에 보관합니다. 연수 공유 화면에도 운영자와 같은 웹앱 이름·썸네일·교사 링크의 **앱 열기**를 표시합니다. 학생 URL은 별도의 **학생 QR**으로 제공하며 추가·설정·유형 수정은 운영자만 할 수 있습니다. 로컬과 운영은 같은 저장소를 사용합니다.

운영자 화면의 **연구소 운영 → 쌀바구니**에서 현재 탭의 독립 경로 `/studies/?admin=1&tab=classes`로 이동하여 내용요소, 연수, 강연 미리보기, Before/After, 포스트잇과 설문을 엽니다. 기존 단독 `withbooong.vercel.app` 배포 두 건은 회수했습니다.

- 화면·실습·로컬 글꼴: `rice-basket/`
- API: `api/rice-basket.js`, 도메인 로직·저장소: `lib/rice-basket/`
- 테스트: `scripts/test-rice-basket*.mjs`, `test/rice-basket/`

운영자용 데이터 API는 기존 `api/admin.js`의 Google 토큰 검증과 운영자 명단 검사를 통과해야 실행됩니다. Firebase `yadoran-2025` 프로젝트의 BOOONG 웹앱(`1:266288546185:web:727060b22ce9643d0c2158`) 로그인을 재사용하며 Firebase 규칙·Functions·다른 앱 설정은 바꾸지 않습니다. 서명·발급 프로젝트·Google 제공자·이메일 인증·운영자 명단을 서버에서 검사합니다. 기존 쌀바구니 비밀번호, 쿠키, localhost 우회는 사용하지 않습니다. 참가자용 `/studies/?s=연수ID` 공유 링크와 해당 연수에 포함된 자료·실습·공개된 설문 작성은 Google 로그인 없이 열립니다. 세션에 없는 페이지, 전체 자료·연수 목록, 생성·수정·삭제·초기화와 설문 결과는 공개되지 않습니다. 웹앱 공유 페이지의 매력 찾기 포스트잇과 댓글은 작성자 이름과 함께 해당 연수 공유 화면에서 모두 조회하고 작성할 수 있습니다. 기존 수업 아이디어·UI/UX 게시판과 개인별 응답은 운영자만 조회합니다. 설문은 `shareResults`가 켜진 경우에만 설문의 결과 보기에서 질문별 객관식 집계와 주관식 답변을 이름 없이 공개합니다. 응답 식별 토큰·해시는 공개하지 않으며, 참가자는 브라우저에 보관된 임의 토큰으로 자신의 설문 응답만 수정합니다. 집계 공개를 끈 설문의 결과는 운영자만 조회합니다.

`?manage=1`은 운영자 확인이 필요한 예전 관리 주소이며, 페이지를 지정하지 않으면 연수 수정 화면으로 이동합니다. 공유용 설문 링크에서는 제거합니다. 관리 화면의 기존 `admin.html?tab=rice-basket` 링크는 독립 경로로 연결됩니다. 화면 임베드는 사용하지 않습니다.

연수 편집의 **연수자**에서 구성원을 코드·이름 버튼으로 복수 선택합니다. 일반 연수생의 응답 참가자와 별도인 `memberCodes`로 저장합니다. 프로필의 세부 연수경력은 이 코드와 구성원의 별칭을 연결해 날짜·연수명·학교를 합산하고 기존 시트의 경력을 유지합니다. 연수 수정·삭제·선택 해제는 프로필을 다시 열 때 반영됩니다. 날짜가 없는 기존 연수는 집계에서 제외하며, 기존 참가자는 자동 추정하지 않습니다.

프로필은 기존 쌀바구니 API의 공개 `GET /api/member-training` 집계를 사용합니다. 선택된 구성원이 있는 연수의 이름·학교·출강일·구성원 코드만 반환하고, 연수 ID·응답·관리 링크는 반환하지 않습니다. 저장소 읽기와 CDN 응답을 각각 최대 30초 캐시하며 같은 서버의 저장 성공 시 읽기 캐시를 지웁니다. 새 함수·저장소·Firebase 설정은 추가하지 않습니다.

Google 계정이 바뀌면 기존 운영자 화면을 비우며, 이전 계정으로 시작한 API 응답을 폐기합니다. 운영자 명단은 서버 전용 `BOOONG_ADMIN_EMAILS`에서 요청마다 확인하며, 미설정·빈 명단·잘못된 이메일 형식이면 접근을 거부합니다. 명단 변경은 서버 재시작 또는 새 배포에 반영됩니다.

자료·연수·설문·응답은 Firebase 전용 콘텐츠 DB `yadoran-2025-booong-content`의 `content/workshop`에 원래 JSON 구조 그대로 저장합니다. 서버 전용 `FIREBASE_BOOONG_CONTENT_SERVER`를 사용하며 다른 앱의 저장소 변수를 사용하지 않습니다. 이전 Blob 원본은 복구용 보관본이며 런타임에서 조회하지 않습니다. `.data`, 비밀번호, 환경 변수와 서버 코드는 정적 내보내기에 포함하지 않습니다. 조건부 저장은 동시 응답을 덮어쓰지 않으며 충돌 시 클라이언트가 최대 두 번 재시도합니다.

빨간벽돌 Before는 기존 다운로드 스냅샷(446b6e026a500456467e4e7f16b153d401ad55ca), After는 원래 연결한 외부 앱을 유지합니다. 외부 GitHub 앱 자체의 공개 범위는 바꾸지 않습니다.

검사: `npm run test:rice-basket`, `npm test`, `npm run check`.

로컬에서는 `npm run serve`로 실행하면 쌀바구니를 Google 로그인 없이 관리할 수 있습니다. 개발 서버가 루프백 주소에 바인딩되고 요청의 Host·접속 주소가 로컬일 때만 적용되며, `NODE_ENV=production` 또는 Vercel에서는 적용되지 않습니다. `.env.local`의 서버 전용 `FIREBASE_BOOONG_CONTENT_SERVER`로 운영과 같은 Firebase `content/workshop`을 직접 읽고 저장합니다. 로컬에서 저장한 연수·자료·유형·웹앱 지정은 재배포 없이 운영에도 반영되며, 이미 열린 운영 화면은 새로고침하면 최신 자료를 읽습니다. 삭제도 운영 자료에 즉시 적용됩니다. 키 누락·연결 실패·저장 충돌 시 오류를 반환하고 로컬 파일로 대체 저장하지 않습니다. 기존 `.data/rice-basket.json`은 보관본이며 자동으로 운영에 덮어쓰지 않습니다. 참가자용 공유 링크는 로컬에서도 기존 공개 권한을 유지합니다. 화면 코드 변경은 계속 배포가 필요합니다.

2026-11-06 로컬 자료는 기존 `연수용 웹앱/.data/withbooong-recovered-1793955464544.json` 복구본의 내용요소 6개·연수 1개를 복사했습니다. 편집 전 복사본은 `.data/rice-basket.original-backup.json`에 보관합니다.

로컬 `/admin.html` 운영자 홈과 연결된 모든 관리 도구는 같은 루프백 제한 아래 Google 로그인 없이 열립니다. 로컬 서버가 공통 인증 모듈을 제공하고, 허용된 관리 API 요청에만 서버 내부 권한을 부여합니다. 운영 배포·외부 접속·다른 Origin 요청에는 적용하지 않습니다. ERP·공지·교과서·왓챠·통계는 기존 데이터 연결을 유지합니다. 쌀바구니는 운영 저장소를 공유하며, 붕모는 별도 문서의 기존 UID 로컬 세션을 사용합니다.

설문 내용요소에서는 연수 카드의 **설문 만들기**로 해당 연수의 문항을 바로 작성하고, **설문 관리**에서 문항을 저장하고 집계 공개를 조절합니다. 연수 목차에는 설문으로 이동하는 항목만 표시하고 질문·결과 집계를 붙이지 않습니다. 참가자는 설문 안의 **결과 보기**에서 공개된 집계를 확인하며, 해당 화면에서만 3초마다 갱신합니다. 객관식은 선택지별 수와 비율, 주관식은 답변 목록을 표시합니다. 집계 공개를 끄면 참가자의 결과 보기도 숨깁니다.

설문 문항은 객관식(단일 선택)·복수 선택·5점 척도·주관식을 지원합니다. 복수 선택은 선택한 항목의 문자열 배열로 저장하며 중복·없는 선택지를 거부합니다. 선택지별 비율의 분모는 해당 문항에 응답한 수이므로 합계가 100%를 넘을 수 있습니다. 5점 척도는 `1`~`5`의 문자열 하나를 저장하고 점수 분포와 평균을 표시합니다. 선택 응답 문항의 미응답은 집계·평균에서 제외합니다. 기존 문항과 응답 데이터의 변환·초기화는 하지 않습니다.

운영자 상단 **연수별 설문 관리** 또는 연수 카드의 **설문 관리**에서 연수별 설문을 엽니다. 공개 설문 주소 복사·열기를 제공하고 **설정**에서 집계 공개를 조절합니다. 각 설문의 **설문 열기**는 운영자용 답변 목록으로 바로 연결하며, 3초마다 변경을 확인합니다. 토큰·해시는 반환하지 않습니다. 공개 주소는 설문을 편집해도 유지합니다.
