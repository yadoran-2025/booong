# 쌀바구니 통합

운영자 화면의 **연구소 운영 → 쌀바구니**에서 현재 탭의 독립 경로 `/rice-basket/?admin=1&tab=classes`로 이동하여 내용요소, 연수, 강연 미리보기, Before/After, 포스트잇과 설문을 엽니다. 기존 단독 `withbooong.vercel.app` 배포 두 건은 회수했습니다.

- 화면·실습·로컬 글꼴: `rice-basket/`
- API: `api/rice-basket.js`, 도메인 로직·저장소: `lib/rice-basket/`
- 테스트: `scripts/test-rice-basket*.mjs`, `test/rice-basket/`

운영자용 데이터 API는 기존 `api/admin.js`의 Google 토큰 검증과 운영자 명단 검사를 통과해야 실행됩니다. Firebase `yadoran-2025` 프로젝트의 BOOONG 웹앱(`1:266288546185:web:727060b22ce9643d0c2158`) 로그인을 재사용하며 Firebase 규칙·Functions·다른 앱 설정은 바꾸지 않습니다. 서명·발급 프로젝트·Google 제공자·이메일 인증·운영자 명단을 서버에서 검사합니다. 기존 쌀바구니 비밀번호, 쿠키, localhost 우회는 사용하지 않습니다. 참가자용 `/rice-basket/?s=연수ID` 공유 링크와 해당 연수에 포함된 자료·실습·공개된 설문 작성은 Google 로그인 없이 열립니다. 세션에 없는 페이지, 전체 자료·연수 목록, 생성·수정·삭제·초기화와 설문 결과는 공개되지 않습니다. 개인별 이름·아이디어·포스트잇·댓글은 운영자만 조회합니다. 설문은 게시되고 `shareResults`가 켜진 경우에만 참가자 공유 화면에 질문별 객관식 집계와 주관식 답변을 이름 없이 공개합니다. 응답 식별 토큰·해시는 공개하지 않으며, 참가자는 브라우저에 보관된 임의 토큰으로 자신의 설문 응답만 수정합니다. 작성 중인 설문과 집계 공개를 끈 설문의 결과는 운영자만 조회합니다.

`?manage=1`은 운영자 확인이 필요한 응답·공유 관리 모드이며 공유용 설문 링크에서는 제거합니다. 관리 화면의 기존 `admin.html?tab=rice-basket` 링크는 독립 경로로 연결됩니다. 화면 임베드는 사용하지 않습니다.

연수 편집의 **BOOONG 참가자**에서 구성원을 코드·이름 버튼으로 복수 선택합니다. 일반 연수생의 응답 참가자와 별도인 `memberCodes`로 저장합니다. 프로필의 세부 연수경력은 이 코드와 구성원의 별칭을 연결해 날짜·연수명·학교를 합산하고 기존 시트의 경력을 유지합니다. 연수 수정·삭제·선택 해제는 프로필을 다시 열 때 반영됩니다. 날짜가 없는 기존 연수는 집계에서 제외하며, 기존 참가자는 자동 추정하지 않습니다.

프로필은 기존 쌀바구니 API의 공개 `GET /api/member-training` 집계를 사용합니다. 선택된 구성원이 있는 연수의 이름·학교·출강일·구성원 코드만 반환하고, 연수 ID·응답·관리 링크는 반환하지 않습니다. 저장소 읽기와 CDN 응답을 각각 최대 30초 캐시하며 같은 서버의 저장 성공 시 읽기 캐시를 지웁니다. 새 함수·저장소·Firebase 설정은 추가하지 않습니다.

Google 계정이 바뀌면 기존 운영자 화면을 비우며, 이전 계정으로 시작한 API 응답을 폐기합니다. 운영자 명단 확인은 기존 BOOONG과 같은 최대 30초 캐시를 사용하고, 만료 후 조회 장애가 나면 접근을 거부합니다.

자료 6개와 연수 1개는 기존 전용 private Blob의 `workshop/store.json`에 유지합니다. BOOONG 프로젝트에만 추가한 `RICE_BASKET_BLOB_READ_WRITE_TOKEN`으로 연결하며 다른 앱의 저장소 변수를 사용하지 않습니다. `.data`, 비밀번호, 환경 변수와 서버 코드는 정적 내보내기에 포함하지 않습니다. 조건부 저장은 동시 응답을 덮어쓰지 않으며 충돌 시 클라이언트가 최대 두 번 재시도합니다.

빨간벽돌 Before는 기존 다운로드 스냅샷(446b6e026a500456467e4e7f16b153d401ad55ca), After는 원래 연결한 외부 앱을 유지합니다. 외부 GitHub 앱 자체의 공개 범위는 바꾸지 않습니다.

검사: `npm run test:rice-basket`, `npm test`, `npm run check`.

로컬에서는 `npm run serve`로 실행하면 쌀바구니만 Google 로그인 없이 관리할 수 있습니다. 개발 서버가 루프백 주소에 바인딩되고 요청의 Host·접속 주소가 로컬일 때만 적용되며, `NODE_ENV=production` 또는 Vercel에서는 적용되지 않습니다. 기존 자료를 복사한 `.data/rice-basket.json`에 저장하고 재시작 후에도 유지합니다. 이 파일이 없거나 손상되면 오류를 반환하며 빈 자료로 대체하지 않습니다. 운영 Blob 자료와 자동으로 동기화하지 않습니다. 참가자용 공유 링크는 로컬에서도 기존 공개 권한을 유지합니다.

2026-11-06 로컬 자료는 기존 `연수용 웹앱/.data/withbooong-recovered-1793955464544.json` 복구본의 내용요소 6개·연수 1개를 복사했습니다. 편집 전 복사본은 `.data/rice-basket.original-backup.json`에 보관합니다.

로컬 `/admin.html` 운영자 홈과 연결된 모든 관리 도구는 같은 루프백 제한 아래 Google 로그인 없이 열립니다. 로컬 서버가 공통 인증 모듈을 제공하고, 허용된 관리 API 요청에만 서버 내부 권한을 부여합니다. 운영 배포·외부 접속·다른 Origin 요청에는 적용하지 않습니다. ERP·공지·교과서·왓챠·통계는 기존 데이터 연결을 유지합니다. 쌀바구니는 위의 로컬 복사본을 사용하며, 붕모는 별도 문서의 기존 UID 로컬 세션을 사용합니다.

설문 내용요소에서는 연수 카드의 **설문 만들기**로 해당 연수의 문항을 바로 작성하고, **설문 관리**에서 저장·응답 받기·집계 공개를 조절합니다. 참가자용 연수 공유 화면은 공개된 설문의 질문·집계를 3초마다 갱신합니다. 객관식은 선택지별 수와 비율, 주관식은 답변 목록을 표시합니다. 집계 공개를 끄면 공유 화면에서도 숨깁니다.

설문 문항은 객관식(단일 선택)·복수 선택·5점 척도·주관식을 지원합니다. 복수 선택은 선택한 항목의 문자열 배열로 저장하며 중복·없는 선택지를 거부합니다. 선택지별 비율의 분모는 해당 문항에 응답한 수이므로 합계가 100%를 넘을 수 있습니다. 5점 척도는 `1`~`5`의 문자열 하나를 저장하고 점수 분포와 평균을 표시합니다. 선택 응답 문항의 미응답은 집계·평균에서 제외합니다. 기존 문항과 응답 데이터의 변환·초기화는 하지 않습니다.
