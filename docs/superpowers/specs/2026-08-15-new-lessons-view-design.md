# 신규 수업 모아보기 설계

## 목표

대시보드 첫 화면에서 모든 과목의 신규 수업을 한곳에 모아 보는 화면으로 진입할 수 있게 한다. 기존 과목별 탐색 흐름은 유지한다.

## 진입점

- 히어로 제목을 `오늘 수업, 이런 건 어떠세요?`로 바꾼다.
- 기존 과목 표지 카드를 `새로 들어온 수업` 링크 카드로 바꾼다.
- 링크는 `index.html?view=new`로 이동한다.
- 링크 전체가 키보드와 포인터로 동작하고 명확한 포커스 상태를 제공한다.

## 신규 수업 화면

- 기존 `index.html`과 대시보드 데이터 로더를 재사용한다.
- `catalog.resources`에서 `isNew`가 참인 자료를 과목과 학교 구분 없이 모두 표시한다.
- 기존 자료 카드와 실제 웹 미리보기 렌더러를 재사용한다.
- 상단에는 `새로 들어온 수업` 제목과 홈으로 돌아가는 링크를 둔다.
- 신규 자료가 없으면 빈 상태와 홈으로 돌아가는 링크를 표시한다.
- 별도 HTML, 별도 데이터 구조, 신규 의존성은 추가하지 않는다.

## 제작자 표기

- 기존 `제작 이름` 문장을 `MADE BY` 레이블과 제작자별 이름 블록으로 바꾼다.
- 제작자 이름은 화면에서 모두 대문자로 표시한다.
- 여러 제작자는 각각 독립된 블록으로 표시한다.

## 검증

- 홈 카드가 `index.html?view=new`를 가리키는지 확인한다.
- 신규 화면에 `isNew` 자료만 표시되는지 확인한다.
- 빈 상태와 홈 복귀 링크를 확인한다.
- 제작자 이름 블록과 대문자 표기를 확인한다.
- 기존 테스트, 자바스크립트 검사, HTML 스모크 검사를 실행한다.
- 데스크톱과 모바일 브라우저에서 레이아웃과 키보드 포커스를 확인한다.
