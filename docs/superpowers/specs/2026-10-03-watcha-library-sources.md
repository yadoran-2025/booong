## 추가 요청: 책 표지

실제 왓챠 목록 응답의 `content.poster.medium`에 표지 URL이 포함됨을 확인했다. 로컬 API 첫 페이지 20권 모두 표지 URL을 반환한다. 표지는 검증한 HTTPS 이미지 호스트를 직접 참조하며 이미지 파일을 서버에 복사하거나 새 의존성을 추가하지 않는다. 네이티브 `loading=lazy`, `decoding=async`, `referrerpolicy=no-referrer`를 사용한다. 제목 옆에 표시하고 부재·실패 시 표지 없음 자리를 유지한다. 기존 캐시는 완료한 도서관 조회와 수동 ISBN을 유지하며 표지 정보만 보완한다.

회귀 검사에서 외부·HTTP·javascript 이미지 주소 거절, 표지 없음, 지연 로딩, 표지 보완 중 기존 결과 유지와 도서관 재조회 없음이 통과했다. 실제 브라우저에서 『외톨이 역을 떠나며』 표지의 정상 로딩(원본 너비 180px)과 기존 조회 225권 유지 상태를 확인했다. 전체 테스트·정적 검사·13페이지 smoke 통과.


## 추가 조회처: 밀리·국립세종·경기도사이버도서관 (2026-10-03)

- 국립세종도서관: 공식 공개 OpenAPI `/openapi/searchStorage.do`의 `kwd=ISBN`, `subCategory=book`, `pageIndex` 검색과 `/search/searchDetail.do?rec_key=…` 권별정보를 조합한다. `manage_code=SJ`와 정확한 ISBN을 검증하고 소장본의 배가상태·이용제한·예약자수를 확인한다. 대출중과 미소장은 구분하며 결과 누락·반복·응답 변경은 조회 실패로 처리한다. [공식 OpenAPI 안내](https://sejong.nl.go.kr/html/c7/c708.jsp?menuId=O716&sel=O700&upperMenuId=O700).
- 경기도사이버도서관: 이전 사이버도서관 주소는 현재 통합안내로 이동하므로 [경기 전자책 서비스](https://ebook.library.kr/)를 사용한다. 사이트 공개 검색의 `/api/service/search-engine?contentType=EB&isbn=…`에서 정확한 ISBN·`SERVICE_USE_YN`·`LOANABLE`을 확인한다. 실물 경기도서관과 별도 선택 항목이다. 전자책과 종이책 ISBN이 다를 수 있어 0건은 ‘동일 ISBN 전자책 없음’으로 표시하며 모든 판본의 미제공을 뜻하지 않는다. 분야별 목록과 원문 검색 링크를 제공한다.
- 밀리의 서재: 실제 `/v3/search` 화면에서 ‘로그인 후 이용 가능한 서비스입니다’를 확인했다. `/v3/search/result/{책제목}` 검색 링크와 분야별 검색 진입을 추가했다. 자동 제공 여부 조회는 지원하지 않으며, 결과를 미소장·대출 가능으로 추정하지 않고 ‘로그인 후 확인’으로 표시한다.
- 기존 캐시의 새 기관 결과가 없으면 해당 기관 선택 시 그 기관만 조회하고 다른 도서관 결과·수동 ISBN 교정은 보존한다. 밀리 선택은 서버 조회 없이 전체 책과 제목 검색 경로를 보여준다.
- 실제 조회: ISBN 9788937448805는 세종 소장·대출중, 경기 전자책 동일 ISBN 없음. ISBN 9788901105956은 세종과 경기 전자책 모두 대출 가능. 유효한 ISBN 9780000000002는 두 기관 모두 0건을 반환했다. 상태는 조회 시점 기준이다.
- 회귀 검사: 기관별 조회 제한·기존 결과 병합·수동 교정 보존·새 기관 선택·밀리 로그인 상태·검색 URL 인코딩·미소장·예약·대출중·다른 ISBN·불완전 응답을 확인했다. 기존 책 상세 화면과 함께 새 조회처를 표시한다.

## 선택한 도서관 우선 조회

- 목록 조회는 선택한 기관만 지정한다. 수원·용인의 지점 선택은 해당 시의 통합 조회 결과를 재사용한다.
- 저장된 ISBN과 기관별 조회 결과를 유지하며, 대출 결과는 15분 동안 재사용한다. 미조회 책 다음으로 가장 오래된 결과부터 갱신하고, 공유 목록에서 겹치는 책은 한 번만 처리한다.
- 책 상세의 ‘도서관 소장·대출 정보’를 펼칠 때 해당 책의 나머지 미조회·오래된 기관을 조회한다. 갱신 중에도 기존 목록을 표시한다.
- 도서관 변경 시 기존 대기열을 멈추고 새 기관의 대기열을 이어간다. 이미 진행 중인 두 건의 응답은 보관한다.
- 관련 회귀 테스트 및 예시 서버의 요청 기록으로 초기 조회 범위, ISBN 재사용, 상세 지연 조회, 갱신 순서와 선택 변경을 검증했다.
